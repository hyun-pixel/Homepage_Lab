# FLOWAX SPACE

FLOWAX SPACE는 승인된 PRD를 기준으로 제작하는 Next.js 기반 단일 스크롤 홈페이지입니다.

## 현재 단계

2단계 프로젝트·Git·에셋 초기 구성.

메인 화면 디자인과 애니메이션은 사용자의 단계 승인 후 시작합니다.

## 실행

1. npm install
2. npm run dev
3. 브라우저에서 http://localhost:3000 확인

## 주요 폴더

- src/app: Next.js 화면과 전역 스타일
- src/components: 이후 단계의 화면 컴포넌트
- src/content: 한국어·영어 콘텐츠
- public/media: 원본 영상, 포스터, 카드 이미지
- public/fonts/licenses: 로컬 글꼴 라이선스

## 데이터와 외부 연결

현재 백엔드, 데이터베이스, 분석 도구, 쿠키, 외부 API와 실제 문의 전송 기능을 사용하지 않습니다.
