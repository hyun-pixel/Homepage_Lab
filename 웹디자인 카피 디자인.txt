1. FIXED BACKGROUND — SCROLL-SCRUBBED VIDEO (the scrolling animation)
------------------------------------------------------------
<div position:fixed; inset:0; z-index:0; overflow:hidden; background:#04060b>
  full-viewport <video> pinned behind all content:
    src="https://cdn.sceneai.art/Hero%20section%20video%20file%20(2)/b6f801fe-12a4-431d-b26c-a5a8c2d2559a.mp4"
    muted playsinline preload="auto"; display:block; width:100%; height:100%; object-fit:cover.
  On top of the video, inside the same fixed div: overlay <div> absolute inset:0 background rgba(4,6,11,0.35).
  (Space in URL encoded as %20. Video is NEVER autoplayed — it is scrubbed by scroll.)
- All page content lives in sibling elements with position:relative; z-index:1, scrolling OVER the video.
- SCRUB LOGIC (in a requestAnimationFrame loop):
    progress = scrollY / (scrollHeight - innerHeight)      // 0..1
    target   = progress * video.duration                   // seconds
    current += (target - current) * 0.1                    // lerp smoothing
    if (Math.abs(target - current) < 0.01) current = target
    if (video.readyState >= 2) video.currentTime = current
  Read video.duration on 'loadedmetadata'.
- PRELOADER: fixed inset:0, z-index:60, bg #04060b, centered percentage text
  (13px, letter-spacing .25em, uppercase, weight 600, color #b9cdea).
  NN% = buffered end / duration (from 'progress' events).
  Fades opacity 1→0 (0.6s) + pointer-events:none on 'canplaythrough' (6s fallback timer).
